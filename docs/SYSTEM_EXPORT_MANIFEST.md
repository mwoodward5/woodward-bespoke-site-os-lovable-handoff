# System Export Manifest

## Included

- `CODEX_MASTER_HANDOFF.md` - always-on operating instructions for the builder.
- `AGENTS.md` - Woodward public web quality rules.
- `engine/` - product spec and JSON intake schema for the click-to-create site builder.
- `factory/` - current generator, smoke, capture, and CA landscape source packet.
- `generated-sites/` - current generated static site bundles.
- `proof/` - teacher packet, screenshots, smoke reports, and deployment evidence.
- `razzle-fx-kitchen/` - visual effect recipes.
- `site-superpowers-kitchen/` - functional recipes.
- `master-glue-kitchen/` - polish, typography, content rescue, local SEO, and QA recipes.
- `scripts/` - kitchen gate and support scripts.
- `docs/LOVABLE_A_PLUS_REVIEW_PROMPT.md` - paste-ready Lovable prompt.

## Excluded

- Real `.env` files.
- Live API keys and secrets.
- Private customer billing data.
- Browser session state.
- Local cache folders.
- Node dependency folders.
