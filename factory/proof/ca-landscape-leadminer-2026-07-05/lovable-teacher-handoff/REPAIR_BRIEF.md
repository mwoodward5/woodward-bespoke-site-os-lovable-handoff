# Repair Brief — What Still Needs Lovable Help

## Goal

Turn the five deployed previews from "working generated drafts" into A+ local-business websites that feel client-ready, cinematic, and specific.

## What Is Better Now

- The sites are deployed and reachable.
- Each site has a different theme, font pair, and hero composition.
- Source logos/images are used when Firecrawl found usable assets.
- Hero videos are present.
- The old quote form was replaced with a richer estimate-studio pattern.
- Internal proof-board language is no longer driving the public homepage.

## What Is Still Not Good Enough

1. The pages still have too much generator rhythm.
2. Some sections still feel like styled cards instead of authored local-business pages.
3. The hero systems are better, but still need more cinematic layering, depth, motion, and art direction.
4. AJP and Barriga lack real source logos/photos, so they still feel proposed instead of personally theirs.
5. Some typography still feels too heavy and blunt in control/button/widget areas.
6. The quote widget is more modern, but should become a more beautiful homeowner configurator.
7. The route pages need to be real pages, not simple card lists.
8. Gallery sections need more life: lightbox, before/after, material details, project storytelling, and image rhythm.
9. Local SEO/AEO content needs to be richer and more natural.
10. We did not run Lighthouse, social preview validators, or full accessibility audits in the final pass.

## Design Direction For Lovable

Use the attached screenshots and generated code as the starting point, but do not preserve weak patterns out of politeness. Repair aggressively.

Target feel:

- premium local contractor, not SaaS dashboard
- cinematic, layered, image-led
- modern 2026/2027 visual surface
- soft but sharp typography
- unique anatomy per business
- real business identity where recoverable
- no repetitive card-grid dependency
- no giant brutal hero type that crushes the viewport
- no generic dark admin look
- no proof-board or internal workflow language on public surfaces

## Specific Repair Requests

- Rebuild each homepage so the five sites no longer feel related by template shape.
- Make the hero for each site use a different composition model:
  - full-bleed cinematic video
  - split editorial/photo essay
  - magazine/local story
  - service-map/navigation-driven
  - material/gallery-led
- Upgrade the quote area into a beautiful homeowner action module.
- Replace flat cards with content sections that feel like a real local business site.
- Add richer service pages and gallery pages.
- Add believable local trust blocks.
- Pull better media/logo/color data where possible.
- Where source assets are missing, generate tasteful proposed brand assets, but label them privately in the handoff, not publicly.
- Preserve noindex until owner approval.
- Preserve public URLs if possible.

## Definition Of A+ For This Batch

Lovable should not call this finished until:

- each site feels visually distinct within 3 seconds
- each site reads like a real local business, not a SaaS/product deck
- each site has strong hero media and section variety
- typography is clearly chosen, not default
- buttons and small UI text feel polished
- quote flow feels premium on mobile
- all images load
- no horizontal overflow
- desktop and mobile screenshots pass visual review
- no internal Woodward/LeadMiner/Ghost Agency language appears on public customer pages
