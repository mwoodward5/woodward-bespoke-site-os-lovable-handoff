# START HERE — Master Glue Kitchen

Third of three companion kitchens.
- `razzle-fx-kitchen` = **how it looks** (visual ingredients)
- `site-superpowers-kitchen` = **how it works** (functional ingredients)
- `master-glue-kitchen` = **the glue** — content rescue, GEO/AEO, local/geo SEO, social everywhere, typography, layouts, first-prompt polish, QC audits, immersive novel effects, legal, deploy, integrations.

## The single most important file
`polish-rules.json` — the machine-readable set of rules the agent applies unprompted on every new site build. This is what makes the first prompt land.
