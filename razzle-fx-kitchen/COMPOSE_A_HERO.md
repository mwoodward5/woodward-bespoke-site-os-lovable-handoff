# COMPOSE A HERO

The `examples/` folder has 64 composed heroes across 8 archetypes × 8 variants.
Each combines a **background** + **type** + **surface** recipe, wired into a single
`index.html` you can open directly.

Archetypes:
- hero-editorial
- hero-brutalist
- hero-cinematic
- hero-industrial
- hero-boutique
- hero-cyber
- hero-magazine
- hero-minimal

Variants (per archetype):
- day-airy, night-dense, calm-corporate, energetic-rebel,
  warm-vivid, cool-monochrome, still-restrained, kinetic-maximal

Recipe layering rule: **background → surface → type**. Always in that z-order.
