# START HERE — Razzle Dazzle FX Kitchen v3 MEGA

You are looking at an **ingredients library** — 600 named recipes, 48 design tokens,
64 composed hero examples, and 1000 natural-language phrase mappings that let a human
or LLM say "make the logo shimmer" and get the right code.

## Read in this order
1. `README.md` — what this is, why it exists, license.
2. `INDEX.md` — full table of contents (or `index.json` for machines).
3. `HOW_TO_ASK.md` — how to phrase requests so the mapper hits.
4. `COMPOSE_A_HERO.md` — walk-through of the 64 composed examples.
5. `REFUSAL_CRITERIA.md` — when NOT to use an effect.
6. `CODEX_HANDOFF.md` — copy-paste prompt for Codex / any agent.
7. Browse `recipes/<category>/<slug>/` — each has README, component.tsx, snippet.html, styles.css, variants.md, preview.png.

## Machine-readable
- `index.json` — full recipe manifest
- `phrases.json` — 1000 natural-language triggers → recipe paths
- `phrases.full.json` — every trigger (~2.4k) for exhaustive matching
- `tokens/*.json` — palettes, easings, keyframes, type pairs, icon systems, grain, mesh
