# Variants — Stamp Icon

- **Intensity:** low / medium / high (adjust animation-duration and opacity)
- **Palette:** override `--c1` and `--c2` custom properties
- **Motion:** set `animation: none` to freeze; component still ships static poster
- **Density:** scale `padding` and typographic ramp
- **Blend:** swap `mix-blend-mode` between overlay / soft-light / screen
