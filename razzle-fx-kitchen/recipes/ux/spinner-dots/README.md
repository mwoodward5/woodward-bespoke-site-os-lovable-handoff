# Spinner Dots

**Category:** ux  **Perf tier:** free  **Reduced-motion:** honored

## What it does
A UX micro-interaction that makes the interface feel responsive and considered.

## Use when
- Content needs a ux treatment with clear brand voice
- You want a drop-in with zero JS dependencies

## Avoid when
- Motion-sensitive audiences without a reduced-motion fallback wired up
- Regulated industries where visual flourish undercuts trust

## Files
- `component.tsx` — React + Tailwind v4 drop-in
- `snippet.html` — framework-free HTML/CSS
- `styles.css` — shared stylesheet
- `variants.md` — tuning knobs
- `preview.png` — 1200×750 poster
