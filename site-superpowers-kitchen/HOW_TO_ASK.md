# HOW TO ASK

Match natural language to a recipe path via `phrases.json`. Examples:

| You say | It maps to |
|---|---|
| "add a support chatbot" | `recipes/ai/chat-support-bot` |
| "read the article aloud" | `recipes/voice/tts-narrate-article` |
| "live cursors for collaborators" | `recipes/realtime/ws-cursors` |
| "Stripe checkout" | `recipes/payments/pay-stripe-checkout` |
| "command palette" | `recipes/ux/cmdk-palette` |
| "generate a hero image" | `recipes/media/image-gen-hero` |
| "semantic search" | `recipes/ai/search-semantic` |
